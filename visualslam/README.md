# visual-slam-dunk

Recipe for success:

- Find SLAM implementation with good access to the code https://github.com/jannikesc/visual-slam-dunk/issues/1
- Find/make NN (or other) that classifies one simple object like cars or humans (or other) https://github.com/jannikesc/visual-slam-dunk/issues/2
- Tweak SLAM code to use the classifed images when making points (color them blue or something)
- Use the blue points to make a bounding box
